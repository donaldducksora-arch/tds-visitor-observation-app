# 来園者行動調査アプリ

## 起動

`index.html` をブラウザで開くと利用できます。入力内容と記録は同じブラウザ内に保存されます。施設マスターや記録データは端末のブラウザ保存領域に置かれます。

iPhoneのSafariで利用できます。ホーム画面に追加してアプリのように起動し、オフラインでも使う場合は、HTTPSで公開したこのフォルダをSafariで開き、「共有」→「ホーム画面に追加」を選んでください。初回アクセス後にオフライン用データが保存されます。PWAのオフラインキャッシュは初回アクセス後に有効になります。file://で直接開いた場合は、ホーム画面追加とService Workerによるオフライン起動が利用できない場合があります。

## 調査の流れ

1. 調査日、観察者ID、グループID、調査条件を入力して開始。
2. 行動カテゴリを選び、施設を検索・選択。「移動・エリア」は8つのテーマポートから選び、「休憩・その他」は移動前・移動後のエリアを選択。
3. 分かる場合だけきっかけ・結果・メモを入力して保存。
4. 「直前を取り消す」で同一セッションの最後の記録を戻せます。
5. 調査終了画面でCSVまたはJSONを出力します。2名の観察者は各自の端末で記録し、出力ファイルを後で統合してください。

## データと施設

施設名・種類・テーマポート・営業状況は別の項目として保持します。複数ポートにまたがる乗り物は1つの施設IDにポート情報を複数保持します。施設一覧には制作指示書のアトラクションと、追加で提供された施設一覧資料のレストラン・ショップ・ショーを登録しています。行動カテゴリを選ぶと、そのカテゴリの施設だけが候補になります。施設名検索は表示中のカテゴリ内を検索します。「移動・エリア」は8つのテーマポートから選択できます。「休憩・その他」では、移動前・移動後のエリアをそれぞれ選択して記録します。記念のショーや季節公演、ワゴンは資料の分類名で登録しています。追加施設は「施設を管理」からカテゴリを指定して登録できます。初期営業状況は「要確認」です。

データはブラウザのローカル保存です。ブラウザデータの消去、端末の変更、プライベートブラウズなどで失われる可能性があるため、調査ごとにCSV/JSONを出力して保管してください。

## 資料について

制作指示書が参照する「東京ディズニーシー アトラクション一覧.docx」は受領ファイル内に見当たらなかったため、施設マスターは指示書本文に列挙された情報を基に作成しています。営業状況は指示書の作成時点の情報を現状確認済みとして扱わず、調査当日に公式情報で確認してください。
